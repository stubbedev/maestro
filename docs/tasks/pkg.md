# Task: internal/pkg — Composer\Package

Port .ref/composer/src/Composer/Package: PackageInterface, CompletePackageInterface, RootPackageInterface, BasePackage (incl. stability constants, getUniqueName/getPrettyString/getFullPrettyVersion with all display modes, packageNameToRegexp, packageNamesToRegexp), Package, CompletePackage, RootPackage, AliasPackage, CompleteAliasPackage, RootAliasPackage, Link (and its String forms), Dumper/ArrayDumper (exact key order and value forms: lock files are written from it), Loader/ArrayLoader (every field, branch-alias handling, aliases), Loader/ValidatingArrayLoader (all warnings/errors verbatim, uses internal/spdx), Loader/JsonLoader, Loader/InvalidPackageException, Loader/LoaderInterface, Version/VersionParser (Composer's subclass: parseNameVersionPairs, isUpgrade), Version/StabilityFilter, Version/VersionBumper, Comparer/Comparer, and Util/PackageSorter + Util/PackageInfo. RootPackageLoader, VersionGuesser and VersionSelector need config/repositories/process: port them too, but against small interfaces defined in this package for the config, repository-set and process dependencies, so later packages plug in (internal/config and internal/util.ProcessExecutor exist already — use them directly where they suffice). Locker and Archiver are NOT in this task (later, with repositories and the archive command).

Design: Go interfaces mirroring PHP's interface hierarchy so the solver and installers can treat alias/root/complete packages polymorphically; packages are hot in the solver (hundreds of thousands loaded from Packagist metadata), so keep them compact, avoid per-package maps where PHP uses fixed properties, intern repeated strings where it helps, and make ArrayLoader fast (it loads every version in p2 metadata). Free-form data (extra, autoload, scripts, support, funding, ...) are *php.Array. Follow docs/PLUGINS.md section 7 (change counters on packages; no package-level mutable state).

Tests: port every test in .ref/composer/tests/Composer/Test/Package (except Locker/Archiver ones) with all providers and fixtures, plus Test/Util/PackageSorterTest. Oracle goldens (tools/oracle/pkg): load many real package definitions (e.g. all versions from a few big Packagist p2 files fetched once into testdata, and Composer's own lock file) through ArrayLoader → ArrayDumper in PHP and Go and compare; ValidatingArrayLoader messages for many invalid inputs; pretty-string forms; Comparer output.

Scope: internal/pkg and subpackages, tools/oracle/pkg. Dependencies: internal/php, internal/semver, internal/spdx, internal/util, internal/config if it exists by the time you need it (another agent is porting it right now; prefer an interface).
Report: public API, test counts, divergences, performance (ArrayLoader packages/sec vs PHP), lint/test status.
