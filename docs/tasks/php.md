# Task: internal/php — PHP runtime semantics

Every other package of the port builds on this API: design it carefully, keep it small, fast, obviously correct and well documented.

1. `Array`: PHP's ordered hash map. Keys are int64 or string with PHP's exact key coercion (decimal-integer strings like "123", "-5" become ints; "05", "1.5", "-0", " 1", out-of-range ints stay strings; bools/floats/nil coerce as PHP does if such setters are exposed), next-free-index tracking for append (after deletes and negative keys, PHP 8.3+ rules), Get/Set/Delete/Has/Len/Append, ordered iteration (`iter.Seq2`), Keys/Values, `IsList` (array_is_list), deep Clone. Plus the array functions Composer relies on with exact semantics: array_merge, array_merge_recursive, array_replace, array_replace_recursive, array_unique, array_keys/values, array_flip, array_slice where useful, sort/rsort/usort/uasort/uksort/ksort/krsort/asort/arsort with PHP 8 stable sort and the flags Composer uses (SORT_REGULAR, SORT_STRING, SORT_NATURAL, SORT_FLAG_CASE). Grep .ref/composer/src and .ref/composer/vendor/composer for what is actually used.
2. Value model: nil, bool, int64, float64, string, *Array, and an ordered `*Object` (stdClass; encodes as `{}` even when empty). PHP 8 loose comparison (`==`, `<=>`) between all of these, as used by sort() with SORT_REGULAR and non-strict in_array/array_search.
3. `JSONDecode` with PHP json_decode semantics (assoc and object mode, big integers become float, depth limit 512, duplicate keys last-wins, invalid UTF-8 errors, exact json_last_error_msg() texts).
4. `JSONEncode` with every flag combination Composer uses: JSON_PRETTY_PRINT (4 spaces, "[]"/"{}" when empty), JSON_UNESCAPED_SLASHES, JSON_UNESCAPED_UNICODE, JSON_PRESERVE_ZERO_FRACTION, JSON_INVALID_UTF8_IGNORE/SUBSTITUTE, JSON_THROW_ON_ERROR, JSON_FORCE_OBJECT; floats identical to PHP with serialize_precision=-1 (verify 1.0e+25, 0.1, -0.0, 1.0e-7 etc. against php); \u escaping of control chars and, without UNESCAPED_UNICODE, of non-ASCII as UTF-16 surrogate pairs; list vs object decided as PHP does.
5. `VarExport` identical to PHP 8.4 var_export for every value type (nested arrays and indentation, `array (` header, string escaping incl. NUL as `'' . "\0" . ''`, floats always with a fraction, NULL/true/false, `\(object) array(` for objects). installed.php and autoload_static.php depend on it byte for byte.
6. String helpers with PHP semantics: strtolower/strtoupper (ASCII-only, PHP 8.2+), ucfirst, lcfirst, ucwords, trim/ltrim/rtrim (default " \n\r\t\v\0" and custom charlists with ranges), str_pad, strnatcmp/strnatcasecmp (exact port of strnatcmp_ex), wordwrap. version_compare is NOT here (internal/semver owns it).
7. PCRE: a `Regexp` wrapper over github.com/dlclark/regexp2 that accepts PHP pattern literals verbatim, delimiters and modifiers included (`{^v?(\d+)$}i`, `#...#x`, `/.../u`, flags i m s x u D U), so other ports paste Composer's regexes unchanged. Translate PCRE-only syntax regexp2 lacks (possessive quantifiers → atomic groups, `\z \A \Z`, `$` with and without D, `\h`, `\R`, `(?P<n>...)`, `\Q..\E` if needed; byte mode without /u vs UTF-8 mode — decide and document). Provide the Composer\Pcre\Preg API Composer uses (match, matchAll, matchStrictGroups, replace, replaceCallback, split, grep, isMatch, quote) with PREG_UNMATCHED_AS_NULL semantics as in .ref/composer/vendor/composer/pcre. Collect EVERY regex used in .ref/composer/src, .ref/composer/vendor/composer/* and .ref/composer/vendor/seld/* and add a differential test: tools/oracle/php/ runs each pattern in real PHP against relevant inputs and writes goldens; the Go test checks every pattern compiles and matches/replaces identically.

Tests: oracle scripts in tools/oracle/php/*.php producing goldens for many tricky inputs (json round trips, floats, unicode, var_export of nested structures, key coercion, mixed-type sorts, natural compare) committed in internal/php/testdata; fuzz targets for JSON round-trip invariants; benchmarks for Array get/set/iterate and JSONEncode with low allocations (no reflection).

Scope: only internal/php, tools/oracle/php, go.mod/go.sum via `go get`.
Report: public API (one line per signature), deliberately omitted PHP semantics, test/golden counts, lint/test status.
