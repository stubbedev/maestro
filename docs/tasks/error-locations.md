# Task: Composer-identical exception locations and -vvv startup lines

Two gaps the command ports found (HANDOFF.md group B/C sections):
1. Exceptions thrown below internal/command render as "In n/a line n/a:" where Composer prints the PHP throw site ("In Factory.php line 317:", "In JsonFile.php line 398:"). Symfony shows that header whenever an exception box is rendered, so this is visible output. Give every Composer exception that can reach the console a throw-site (PHP file basename + line, exactly as Composer 2.10.3's source has it): design one mechanism (e.g. a small `phperr` helper/type in a low package that records class, file and line at construction, used by every port's error constructors), apply it across the ported packages at every throw site that can surface to the user (grep the PHP source for `throw new` and map each to its Go site), and make the console's renderer use it. Include the exception class name rendering for -v ("[RuntimeException]" boxes) and previous-exception chains as Symfony renders them.
